# Проект Marketplace

![ГУАП](https://src.guap.ru/logos/guap/s_guap-main.svg)

## Описание проекта

Marketplace — это веб-приложение для создания онлайн-рынка, где пользователи могут продавать и покупать товары. Проект включает функционал для регистрации пользователей, добавления товаров, поиска товаров по категориям, оформления заказов и управления профилем.

## Основные функции

- **Регистрация и авторизация пользователей**
- **Добавление товаров с возможностью загрузки изображений**
- **Поиск товаров по категориям, цене и рейтингу**
- **Корзина для покупок**
- **Оформление заказов**
- **Управление профилем пользователя**
- **Админ-панель для управления товарами и пользователями**
- **Новая запись**
